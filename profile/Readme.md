# Reproducibility in Digital Health

Reproducibility in Digital Health is an initiative focused on methodological transparency, software heritage, and research reproducibility in digital health.

## Objectives
- Promote open science practices and software reproducibility across health research projects.
- Develop methods, workflows, and datasets to identify, document, and evaluate digital tools used in biomedical research.
- Facilitate collaboration between researchers, software engineers, and health professionals.

## Events

### Hackathon: Software Extraction in PEPR Santé Numérique Corpus (Marseille, Oct 13–15, 2026)
Organized during the 2026 Annual Days of PEPR Santé Numérique at Campus Biaggi (Marseille), this first hackathon focused on mining scientific literature to identify software referenced, utilized, or developed within the PEPR Santé Numérique initiative.

- **Main Goal:** Build pipelines for automatic identification and cataloging of software entities in research publications.

- **Key Tools:**
  - [Softcite](https://github.com/softcite): Machine learning tool for software mention extraction.
  - [BioToFlow](https://academic.oup.com/bioinformatics/article/42/8/btag565/8747618): Workflow and software connectivity analysis.
  - [Baguette](https://huggingface.co/buckets/dataesr/Baguette-Software-Dataset)A small generative model from the French Ministry's dataESR team. For each paragraph it extracts software and dataset mentions.

- **Repository:** [`hackaton-sante-numerique-2026`](https://github.com/ReproducibilityDigitalHealth/hackaton-sante-numerique-2026)
